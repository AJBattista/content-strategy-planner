# Project Conventions

## Stack

- **Framework:** Next.js 14 with App Router
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Hosting:** Vercel

## Design System

### Background & Surfaces

- Deep navy / near-black background
- Slate / charcoal panels
- Soft white text for primary content
- Muted cool gray for secondary text

### Status Colors

- **Steel blue** — neutral status
- **Muted teal** — strong fit
- **Amber** — caution
- **Muted red** — weak fit

### Channel Accent Colors

- **Muted magenta** — Instagram
- **Subdued cyan** — TikTok
- **Controlled blue** — LinkedIn
- **Amber** — Email
- **Emerald** — SEO/Blog
- **Violet** — Webinar

### Labels

Use executive language only:

- Forecast Traffic
- Forecast Conversions
- Forecast Revenue
- Benchmark Fit
- Recommended Mix

## UI Rules

- No decorative UI elements that don't affect the recommendation
- No chat sidebars
- No spinning score wheels
- No AI assistant panels
- No creativity scores
- Mobile responsive required
